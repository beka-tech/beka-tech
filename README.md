### 🧭 About Me

I'm a **backend-focused Full Stack Developer** building modern web applications and production-ready APIs with **C#, ASP.NET Core, Angular, and PostgreSQL**.

My main interest is **backend engineering** — designing maintainable APIs, modeling business domains, structuring applications with **Clean Architecture**, and building reliable application workflows using **CQRS and MediatR**.

I'm currently strengthening my understanding of **distributed systems, caching, concurrency, API design, background processing, and scalable backend architecture**.

My long-term direction is to grow from a backend-focused full stack developer into a strong **Backend / .NET Engineer**, working on **distributed, high-performance, production-scale systems**.
